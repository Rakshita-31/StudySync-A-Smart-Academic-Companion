
# StudySync

StudySync is a **full-stack student productivity platform** built to showcase practical skills in **React, Firebase, and analytics-driven UI design**. It improves student focus and consistency by unifying core academic tools into a single, scalable application.

> 🚧 **Status:** Ongoing project under active development, demonstrating iterative design and continuous improvement.

 ✨ Key Features

* **Active Focus Validation (AFV):** Custom logic to validate meaningful study sessions

* **Pomodoro-Based Focus System:** Structured focus and break cycles

* **Task Management:** CRUD-based task tracking with completion insights

* **Journaling:** Cloud-persisted daily reflections

* **GPA Calculator:** Rule-based academic performance computation

* **Analytics Dashboard:** Visual insights derived from user activity datazation:## 🛠 Tech Stack

* **Frontend:** React

* **Backend & Database:** Firebase (Authentication, Firestore)

* **Analytics:** Chart-based data visualization

* **Architecture:** Component-based, scalable, Core Concept – Active Focus Validation (AFV)

AFV is the core innovation of StudySync. Instead of tracking time alone, it distinguishes **active engagement from passive usage**, reinforcing disciplined and intentional study behavior.
